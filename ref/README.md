# Reference Library

This directory is a structured reference library for Codex and human experiment tracking.

## Layout

```text
ref/
  papers/       # large PDFs, ignored by git
  code_notes/   # committed source-code maps
  data_cards/   # committed dataset cards
  equations/    # committed formula notes
  figures/      # committed small notes; large images ignored unless intentionally added
```
